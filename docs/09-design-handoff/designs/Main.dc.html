LabConnect Provisional brand values · OQ-19

Design handoff · D-02 · 25 Nov 2026

LabConnect: find, book and verify NABL-accredited testing

First visual design for the MVP flow: discover → book → lab accepts → pay → self-drop → Maker records → Checker approves → test → report with QR verification → 72-hour dispute window → payout.

Provisional brand. The blue (#1F6FA8) and the Poppins typeface are stand-ins chosen for this draft. They are not QCI-approved values. QCI's guidelines name "Q Blue" and black but give no colour codes and no web typeface (OQ-19). Swap the --qci-* tokens when the official values arrive; no component changes.

How to read this canvas

Each page is one stage of the master prompt. Blue notes under each screen list the API fields it uses (from packages/api-contract).

Phone screens are 360 px, tablet 768 px, desktop 1280 px. Strips show several phone steps side by side.

Clickable prototype (J1): start at B1 Search and press Play. Primary buttons link to the next screen. J6 hold: C7 Hold. J7 report returned: D3 Review.

Assumptions in this draft

  • Header lockup: the supplied QCI standard logo, unaltered, on white, with "LabConnect" as plain text beside it. The endorsement wording is a placeholder (OQ-19, OQ-12).
  • Lab staff names are hidden from customers in timelines; only roles show (contract rule OQ-29). This differs from UX principle 5's example.
  • The verification page shows the approving Checker's name and designation (OQ-15 default).
  • All people, labs, numbers and amounts are illustrative sample data.
